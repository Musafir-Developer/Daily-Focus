# Daily Focus | Simple To-Do List

A clean, modern, and responsive single-file To-Do List web application designed to help you organize your day with zero friction. Built with semantic HTML, Tailwind CSS, and vanilla JavaScript—ready.

## ✨ Features

- **Add, Complete & Delete Tasks:** Quickly add tasks, mark them as done, or remove them with a single click.
- **Smart Filtering:** Easily switch between **All**, **Active**, and **Done** tasks.
- **Automatic Local Storage:** Your tasks are automatically saved in your browser's `localStorage`, so your list stays intact even after refreshing or closing the tab.
- **Live Progress Counter:** Displays your current completion progress (`X of Y completed`) alongside today's date.
- **One-Click Cleanup:** Clear all completed tasks at once with the **Clear done** button.
- **Zero Build Tools Required:** Everything lives inside a single `index.html` file—no `npm`, bundlers, or backend setup needed.


## 💻 Running Locally

Simply download `index.html` and double-click it to open it directly in any modern web browser (Chrome, Firefox, Safari, or Edge).

## 🛠️ Built With

- **HTML5** — Semantic structure and accessible controls
- **Tailwind CSS (via CDN)** — Clean, responsive utility-first styling
- **Vanilla JavaScript (ES6+)** — State management, XSS-safe rendering, and `localStorage` persistence
